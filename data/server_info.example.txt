# Generic Server Context Template

Use this file as a structured Markdown knowledge base for the server's
documented lore and facts. Keep private deployment-specific information in
`data/server_info.txt`; that file is excluded from Git.

Organize information under clear headings and subsections. Short, focused
sections help local RAG retrieve only the relevant context for each question.
Prefer one topic, event, relationship, or group of aliases per section. Use
canonical names consistently and list common nicknames explicitly.

## Server
Name: {server_name}
Purpose: Discord community.

## History
This server was created by its administrators. Document its origin, ownership,
and important historical details here.

## Important Events
Add public and relevant server events here. Use a separate `###` subsection for
each event and include its date or period when known.

## BandiBot

playback, and web search. It uses the {model_name} language model.

## General Notes
Add stable definitions, recurring groups, and other context here.

## Members, Aliases, and Relationships
- Canonical member name: common nickname or alias
- Member relationship: documented relationship

## Privacy and Accuracy
- Include only information that the bot is allowed to use in responses.
- Mark uncertain or deliberately private details clearly.
- Do not add API keys, tokens, passwords, or other secrets.
